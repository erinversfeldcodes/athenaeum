# Security

## Reporting a vulnerability

Please report a vulnerability privately, through
[GitHub's private vulnerability reporting](https://github.com/erinversfeldcodes/athenaeum/security/advisories/new)
on this repository's Security tab. Do not open a public issue for it.

Your report is visible only to you and the maintainer.

## Scope

This repository holds instructions that agents follow, so reports
are especially welcome for:

- Content here that would lead an agent to leak a secret, weaken a test, skip
  a review or act outside its ticket
- A way for text in a ticket, a comment or a managed repository to override
  what a skill instructs

## Response

The maintainer will acknowledge a report within 5 business days and aim to give
a fix or mitigation timeline within 30 days for a confirmed vulnerability. Once
a fix is out, the advisory is published with credit to you.

## Supported versions

The repository holds no content yet. Only the latest commit on `main` is
supported.
